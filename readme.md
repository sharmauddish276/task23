# Greenwood Public Library Website

## Description
Greenwood Public Library is a responsive website built using HTML
and Tailwind CSS. It presents library sections, books, membership
plans, events and contact information.

## Technologies Used
- HTML
- Tailwind CSS CDN

## Features
- Sticky navigation bar
- Responsive navigation links
- Gradient hero section
- Call-to-action buttons
- Dashboard preview
- Three floating information cards
- Library statistics
- Library sections
- Responsive image gallery
- Values section
- About section
- Four membership cards
- Testimonial section
- Contact section
- Upcoming events
- Multi-column footer
- Fixed chat widget
- Hover effects and transitions

## How to Run
1. Open the project folder in VS Code.
2. Open index.html in your browser.
3. You can also use the Live Server extension.

An internet connection is required to load Tailwind CSS and images.
